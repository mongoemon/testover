testover · เส้นทางผู้ใช้

ผู้ใช้ทำอะไรบนเว็บได้บ้าง

Task Board คือเว็บจดงานเล็กๆ หน้านี้พาตามดูทีละขั้นว่าผู้ใช้เข้ามาแล้วทำอะไรได้ จะไปหน้าไหนต่อ และเจออะไรเมื่อกรอกผิด พร้อมผังที่ไล่ตามด้วยตาได้ทันที

วิธีรันแอป รันในเครื่องด้วย npm start แล้ว login ด้วย demo / demo1234

ผู้ใช้ทำอะไรได้บ้าง

6 อย่างหลักที่เว็บเปิดให้ทำ ส่วนหัวข้อถัดไปอธิบายแต่ละอย่างเป็นผังและข้อความ

1

สมัครสมาชิก

ตั้ง username 3–20 ตัว, ชื่อที่แสดง และรหัสผ่านอย่างน้อย 8 ตัว

2

เข้า/ออกจากระบบ

ลองเร็วๆ ด้วยบัญชี demo / demo1234 กด Logout ได้จากแถบบนทุกหน้า

3

จัดการงาน

เพิ่ม ติ๊กเสร็จ แก้ชื่อ ลบ พร้อมระดับ Low / Medium / High

4

ค้นหาและกรอง

พิมพ์เพื่อค้นหา, กรอง All / Active / Completed และดูว่าเหลือกี่งาน

5

ดูแลโปรไฟล์

เปลี่ยนชื่อที่แสดงและเปลี่ยนรหัสผ่าน

6

ปรับแต่งและลบบัญชี

เปิด dark mode หรือลบบัญชีพร้อมงานทั้งหมด (มีกล่องยืนยัน)

แผนที่หน้าเว็บ

เว็บมี 4 หน้า ผู้ใช้เดินไปมาระหว่างกันตามลูกศร หน้าที่ต้อง login ก่อนคือ Tasks และ Profile

1 · เข้าเว็บและยืนยันตัวตน

ทุกคนเริ่มที่นี่ ระบบตัดสินใจให้ว่าจะไป Tasks หรือ Sign in ตามว่ายังมี session ค้างอยู่ไหม

อ่านเป็นข้อความ
  1. เปิดเว็บ: ถ้ามี session ค้างอยู่ จะเข้า Tasks ทันที ไม่มีก็ไปหน้า Sign in
  2. กรอก username + password แล้วกด Login: ถูกต้อง → Tasks, ผิด → ข้อความสีแดง แล้วลองใหม่
  3. ยังไม่มีบัญชี: กด Create account → กรอก 4 ช่อง → ถ้าผ่านกติกาจะเข้า Tasks พร้อมข้อความต้อนรับ ถ้าไม่ผ่านจะเห็นรายการข้อผิดพลาดทั้งหมดพร้อมกัน

2 · จัดการงาน

หน้าหลักของเว็บ อยู่ที่ Tasks ผังนี้ตามชีวิตของงาน 1 ชิ้น ตั้งแต่พิมพ์ชื่อจนถูกลบ

อ่านเป็นข้อความ
  1. พิมพ์ชื่องาน เลือก Priority (Low / Medium / High ค่าเริ่มต้น Medium) แล้วกด Add task
  2. ชื่อว่างหรือเกิน 80 ตัว → ข้อความสีแดง งานยังไม่ถูกเพิ่ม
  3. ผ่าน → งานขึ้นท้ายรายการและบันทึกทันที
  4. แต่ละแถว: ติ๊กเสร็จ / Edit / Delete และปุ่ม Clear completed ลบทุกงานที่เสร็จแล้ว (ปุ่มกดไม่ได้ถ้ายังไม่มีงานที่เสร็จ)

ค้นหา

พิมพ์ในช่อง Search tasks รายการกรองตามไปทีละตัวอักษร ไม่สนตัวพิมพ์ใหญ่เล็ก ไม่เจอจะขึ้น No matching tasks

กรอง

ปุ่ม All / Active / Completed สลับมุมมอง ปุ่มที่เลือกอยู่จะถูกเน้น และใช้ร่วมกับการค้นหาได้

นับงานที่เหลือ

ท้ายรายการบอกว่า “N tasks left” คือจำนวนงานที่ยังไม่ติ๊กเสร็จ

3 · ดูแลโปรไฟล์

หน้า Profile แบ่งเป็นการ์ด 4 ใบ แต่ละใบทำงานแยกกัน ผิดที่ใบไหนก็แจ้งเตือนเฉพาะใบนั้น

อ่านเป็นข้อความ
  1. Details: แก้ชื่อที่แสดง ห้ามว่าง สำเร็จจะขึ้น Profile updated และชื่อบนแถบบนเปลี่ยนทันที
  2. Password: ต้องใส่รหัสเดิมให้ถูก รหัสใหม่อย่างน้อย 8 ตัวและยืนยันให้ตรงกัน สำเร็จจะขึ้น Password changed
  3. Appearance: ติ๊ก Dark mode สลับธีมทันทีและจำไว้
  4. Danger zone: Delete account ถามยืนยันก่อน ถ้ายืนยันจะลบบัญชีกับงานทั้งหมดแล้วกลับ Login

ข้อควรรู้

  • ข้อมูลอยู่บน server บัญชีกับงานเก็บในหน่วยความจำของ backend ล็อกอินจากเบราว์เซอร์ไหนก็เห็นข้อมูลเดิม แต่ทุกอย่างจะรีเซ็ตเมื่อ server restart เบราว์เซอร์จำแค่ session กับธีม แต่ละบัญชีมีรายการงานของตัวเอง ไม่ปนกัน
  • username ไม่สนตัวพิมพ์ใหญ่เล็ก ระบบแปลงเป็นตัวพิมพ์เล็กให้ และใช้ได้เฉพาะ a–z, 0–9 และ _
  • ต้อง login ก่อนเข้า Tasks และ Profile ถ้าพิมพ์ URL ตรงๆ จะถูกส่งไป Sign in พร้อมข้อความ ส่วนคน login แล้วที่เปิดหน้า Sign in หรือ Register จะถูกส่งไป Tasks
  • URL ที่ไม่มีอยู่ จะเห็น Page not found พร้อมลิงก์กลับหน้าแรก
  • ป้ายเวอร์ชันมุมขวาล่าง กดค้างประมาณ 0.6 วินาทีเพื่อเปิด change log (ใช้คีย์บอร์ดกด Enter หรือ Space ได้)
  • ลิงก์ Docs บนแถบเมนูและหน้า Sign in พามาที่เอกสารชุดนี้
ข้อควรระวัง: นี่คือแอปตัวอย่างสำหรับฝึกทดสอบ ข้อมูลอยู่ในหน่วยความจำของ server และหายเมื่อ restart บัญชี demo ใช้ร่วมกัน ห้ามใช้รหัสผ่านจริงของคุณ
