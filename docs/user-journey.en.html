What can a user do on the site?

Task Board is a small to-do site. This page follows a user step by step: what they can do, where they go next and what they see when they get something wrong, with diagrams you can trace by eye.

Open the live app Sign in with demo / demo1234

What users can do

The six main things the site offers. The sections below explain each one with a diagram and text.

1

Create an account

Pick a 3–20 character username, a display name and a password of at least 8 characters.

2

Sign in and out

Try it quickly with demo / demo1234. Logout sits in the top bar on every page.

3

Manage tasks

Add, complete, rename and delete tasks, each with a Low / Medium / High priority.

4

Search and filter

Type to search, filter by All / Active / Completed and see how many are left.

5

Look after your profile

Change your display name and your password.

6

Personalise and leave

Turn on dark mode, or delete the account with all its tasks (after a confirmation).

The page map

The site has four pages and users move between them along the arrows. Tasks and Profile need a signed-in user.

1 · Opening the site and signing in

Everyone starts here. The site decides between Tasks and Sign in depending on whether a session is still saved.

Read it as text
  1. Open the site: with a saved session you go to Tasks at once, otherwise to Sign in.
  2. Enter username + password and press Login: correct → Tasks, wrong → red message, retry.
  3. No account yet: press Create account → fill 4 fields → if the rules pass you land on Tasks with a welcome message, otherwise every error is listed at once.

2 · Managing tasks

The heart of the site. This chart follows one task from typing its title to deleting it.

Read it as text
  1. Type a title, pick a Priority (Low / Medium / High, default Medium) and press Add task.
  2. An empty title or one over 80 characters → red message, nothing is added.
  3. Valid → the task is appended to the list and saved at once.
  4. Per row: complete / Edit / Delete, and Clear completed removes every finished task (disabled while none are finished).

Search

Type in Search tasks and the list narrows as you type, ignoring case. No hits shows No matching tasks.

Filter

The All / Active / Completed buttons switch the view. The active one is highlighted and it combines with search.

Count what is left

The footer reads “N tasks left”, the number of tasks not yet completed.

3 · Looking after the profile

The Profile page is four cards that work independently. A mistake in one only shows its own message.

Read it as text
  1. Details: change the display name; it cannot be empty. Success shows Profile updated and the greeting in the header changes at once.
  2. Password: the current password must be right, the new one at least 8 characters and confirmed. Success shows Password changed.
  3. Appearance: tick Dark mode to switch themes at once; the choice is remembered.
  4. Danger zone: Delete account asks first; if confirmed it removes the account and all its tasks and returns to Login.

Good to know

  • Data lives only in this browser. It is kept in localStorage with no backend, so switching browsers or clearing site data loses it. Every account has its own task list.
  • Usernames are case-insensitive. They are lowercased for you and may only use a–z, 0–9 and _.
  • You must sign in for Tasks and Profile. Typing the URL directly sends you to Sign in with a notice; a signed-in user opening Sign in or Register is sent to Tasks.
  • Unknown URLs show Page not found with a link back home.
  • The version badge in the bottom-right corner opens the change log when you press and hold for about 0.6 seconds (keyboard: Enter or Space).
  • The Docs link in the top bar and on the Sign in page leads to this documentation.
Heads-up: This is a demo app for practising tests. Passwords are stored as plain text in localStorage on purpose, so never use a real password.
